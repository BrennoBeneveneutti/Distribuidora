Manual de uso - Cadastro de Peças

01

Para que serve

O programa cadastra as peças do sistema em um banco de dados MySQL.

02

Cadastrar uma peça

  1. Preencha os campos da tela.
  2. Clique em Cadastrar.
  3. Se tudo estiver correto, aparece a mensagem de confirmação.
03

Outras opções

  • Limpar (ou Arquivo > Limpar campos): esvazia todos os campos.
  • Fechar (ou Arquivo > Sair): encerra o programa.
  • Ajuda > Sobre: mostra os autores e a versão.
04

Requisitos

  • Java 8 ou superior;
  • Servidor MySQL em execução.
